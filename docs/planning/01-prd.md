## 1. 문제 정의

### 1.1 현재 상황 (As-Is)

경기도의회에서 본회의나 상임위원회가 열리면:
- **여러 직원이 실시간 스트리밍을 동시에 모니터링**해야 함 (중복 업무)
- **3시간 이상 긴 회의**에서 특정 발언을 찾으려면 전체 영상을 다시 봐야 함
- **공식 회의록**이 늦게 나와 후속 업무가 지연됨

### 1.2 목표 상황 (To-Be)

- 실시간 자막으로 **텍스트만 보고도 회의 흐름 파악** 가능
- **키워드 검색**으로 특정 발언 시점 즉시 찾기
- 공식 회의록 전에 **빠른 내부 정리** 가능

### 1.3 왜 지금인가? (Why Now)

- 클라우드 STT(Deepgram Nova-3)의 한국어 정확도가 실용 수준에 도달 (초기 Whisper API → Deepgram으로 전환)
- 조직 내 디지털 혁신 필요성 증가
- 직원 업무 부담 해소 필요

## 3. 사용자 스토리

### FEAT-0: 접속/인증
- [ ] 사용자로서, URL 접속만으로 서비스를 사용할 수 있어야 한다. (MVP: 인증 없음)
- [ ] (v2) 사용자로서, 접속 권한 관리가 가능해야 한다.

### FEAT-1: 실시간 자막 (MVP)
- [ ] 직원으로서, 실시간 스트리밍 영상과 자막을 동시에 볼 수 있어야 한다. 왜냐하면 누가 말하는지 확인하면서 내용을 파악해야 하기 때문이다.
- [ ] 직원으로서, 자막이 5초 이내 지연으로 표시되어야 한다. 왜냐하면 실시간 모니터링의 의미가 있어야 하기 때문이다.
- [ ] 직원으로서, 지금까지 나온 자막 히스토리를 스크롤해서 볼 수 있어야 한다. 왜냐하면 놓친 내용을 확인해야 하기 때문이다.
- [ ] 직원으로서, 자막 클릭 시 해당 시점으로 영상이 이동해야 한다. 왜냐하면 특정 발언을 다시 들어야 할 때가 있기 때문이다.

### FEAT-2: 키워드 검색 (MVP)
- [ ] 직원으로서, 자막에서 키워드를 검색하면 하이라이트되어야 한다. 왜냐하면 3시간 회의에서 특정 내용을 빠르게 찾아야 하기 때문이다.

### FEAT-3: VOD 자막 (MVP)
- [ ] 직원으로서, VOD URL을 등록하면 자막이 생성되어야 한다. 왜냐하면 지난 회의도 검색 가능해야 하기 때문이다.
- [ ] 직원으로서, VOD 목록에서 지난 회의를 선택할 수 있어야 한다.

### FEAT-4: 정확도 향상 (MVP)
- [ ] 직원으로서, 의원 이름이 정확하게 인식되어야 한다. 왜냐하면 누가 발언했는지가 중요하기 때문이다.
- [ ] 직원으로서, 의회 전문 용어가 정확하게 인식되어야 한다.

### FEAT-5: AI 요약 (v2)
- [ ] 직원으로서, 회의 전체 요약을 AI가 생성해주어야 한다.

### 5.3 Non-goals (명시적 제외)

- 화자 기반 영상 편집 - 미구현
- 외부 공개 - 내부 도구로만 사용

### 5.4 MVP 이후 구현 완료 기능 (Phase 4~9)
- **채널 시스템**: 18개 HLS 채널 + STT 제어 + 방송 상태 SSE (Phase 4)
- **화자 식별**: Deepgram diarize + 화자별 색상 표시 (Phase 5)
- **자막 수동 교정**: 편집 페이지 + 변경 이력 추적 (Phase 5~6A)
- **교정 도구**: 용어 점검 + AI 문법 검사 + PII 마스킹 (Phase 6B)
- **의안 관리**: 의안 CRUD + 회의 연결 (Phase 5)
- **통합 검색**: 전체 회의 자막 검색 + 필터 (Phase 5)
- **회의록 내보내기**: 4형식 (markdown/srt/json/official) (Phase 5)
- **대조 관리**: 검토 대기열 + 일괄 처리 (Phase 7)
- **AI 회의 요약**: 안건별 요약 + 핵심 결정 + 후속 조치 (Phase 7)
- **실시간 자막 교정**: OpenAI 배치 큐 교정 (Phase 8)
- **Railway 안정성**: Self-ping + AutoStt 정리 (Phase 8)
- **플랫폼 셸 UI**: 사이드바 8모듈 + 상단 헤더 + 브레드크럼 (Phase 9)
- **Phase 11 개선**: 메인화면 개선 + AI 어시스턴트 + 권한 체계 (진행중)

## 7. 해결 가설과 실험

### 7.1 가설
> 만약 실시간 자막을 5초 이내로 제공하면, 직원들의 모니터링 부담이 크게 줄어들 것이다. 왜냐하면 영상을 보지 않고 텍스트만 훑어봐도 내용 파악이 가능하기 때문이다.

### 7.2 실험 루프

| 단계 | 내용 |
|------|------|
| 실험 | 1회 본회의에서 실시간 자막 사용 |
| 관측 | 자막 지연 시간, 모니터링 인원 수 |
| 학습 | 5초 달성 여부, 업무 효율 향상 체감 |
| 다음 | 검색 기능 활용도 측정 |

## 9. Phase 11 개선 목표 (진행중)

### 9.1 메인화면 개선
- **생중계 현황 대시보드**: 18개 채널 실시간 상태 + 현재 진행중인 안건 표시 (대체 위치: S-01 중단면)
- **AI 실시간 요약 카드**: 생중계 중인 회의의 핵심 내용을 GPT-5-mini로 실시간 요약 (최신 5분 자막 기반)
- **우측 고정 AI 채팅 패널**: 회의록/의안/의원 데이터 기반 Q&A (가능 시 좌측 패널로 스위칭)

### 9.2 AI 어시스턴트
- **신규 화면 S-14** (`/ai`): 전용 대화형 Q&A 페이지
  - 회의록, 의안, 의원정보, 통계 데이터를 컨텍스트로 학습
  - 사용자 질문에 RAG 방식으로 답변 (GPT-5-mini 사용)
  - 대화 이력 저장 (ai_conversations 테이블)
- **VOD 뷰어에 AI 패널**: 해당 회의 맥락의 Q&A 기능 추가
- **실시간 뷰어에 AI 요약**: 생중계 중 핵심 요약 자동 제공

### 9.3 권한 체계 도입
- **비로그인 공개 조회**: 일반직원은 생중계/회의록/AI 조회 (로그인 불필요)
- **로그인 편집 권한**: VOD 등록, 자막 편집, 의안 관리는 로그인 후 가능
- **신규 화면 S-15** (`/login`): 역할 기반 인증 페이지
- **신규 화면 S-16** (`/stenography`): 속기사 전용 대시보드 (작업 큐, 진행중 편집, 완료 목록)
- **사이드바 메뉴 제어**: 역할별 활성화/비활성화 (회의 미선택 시 일부 모듈 disabled)
- **위원회 필터 기본값**: 전문위원실 직원은 소관 위원회 자동 필터 적용

### 9.4 속기 편집 UX 대폭 개선
- **텍스트 중심 레이아웃**: 화면 80%+ 텍스트, 음성 플레이어 상단 고정 (최소 UI)
- **음성-텍스트 통합 편집**: 음성 들으며 타이핑, STT 참고바는 접힘/펼침
- **AI 자동 교정**: 화자 자동 구분, 맞춤법/용어 교정, 문단 자동 구분
- **수정 이력 추적**: 누가/언제/무엇을 수정했는지 diff 표시 (stenography_edit_history 테이블)
- **편리한 인라인 수정**: 시간/화자 드롭다운 빠른 전환

## Decision Log

- D1: API vs 로컬 → API 선택 (GPU 없음) → **Deepgram Nova-3 Streaming으로 최종 결정**
- D2: 화자 분리 방식 → **Deepgram diarize=true로 구현 완료** (Phase 5)
- D3: 클라우드 환경 → Railway + Supabase + Vercel
- D4: 프론트엔드 → Next.js 14 (App Router)
- D5: 실시간 통신 → 네이티브 WebSocket (Socket.io 미사용)
- D6: STT 엔진 → Whisper에서 **Deepgram Nova-3**로 전환 (실시간 스트리밍 지원)

- D8: DB 접근 → asyncpg 대신 **Supabase REST API** (Windows 한글 이슈)
- D9: AI 교정 → **OpenAI GPT-5-mini 배치 큐** (비동기 교정)
- D10: UI 레이아웃 → Header 기반에서 **PlatformLayout 사이드바 기반**으로 전환 (Phase 9)
