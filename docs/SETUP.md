# 다른 의회가 이 서비스를 띄우는 법

이 문서는 **경기도의회가 아닌 기관**이 이 소스로 자기 회의 자막을 만들 때의 순서입니다.
경기도의회 운영 절차는 `deploy/ncp/README.md` 를 보세요.

가장 짧은 답: **OpenAI 키를 넣고 → DB 를 만들고 → 관리자 화면에서 생중계 주소를 등록하면** 자막이 나옵니다.
아래는 그 세 줄을 푼 것입니다.

---

## 0. 무엇이 되고 무엇이 안 되나

| 되는 것 | 조건 |
|---|---|
| 생중계 실시간 자막 | OpenAI 키 + 생중계 영상 주소(m3u8) |
| 자막 검색·회의록 내보내기·AI 요약·AI 질의응답 | 위와 같음 |
| 화자(발언자) 이름 | + **의원 명부를 DB 에 넣어야** 합니다. 없으면 자막은 나오지만 화자가 전부 `위원장` 으로 굳습니다 |
| 다시보기(VOD) 자막·속기록·안건·발언영상 클립 | 기관 영상관리시스템이 경기도의회 KMS 와 같은 규격이어야 합니다. 아니면 **어댑터를 만들어야** 합니다 |

**이번 판에서 여는 것은 생중계 자막입니다.** 나머지는 설정을 비우면 조용히 꺼지고, 서비스는 정상 동작합니다.

---

## 1. 필요한 것

- Python 3.11+ / Node.js 20+
- PostgreSQL 16 + [PostgREST](https://postgrest.org) (앱은 PostgREST 를 통해 DB 에 붙습니다)
- OpenAI API 키 — **콘솔에서 월 한도를 먼저 거세요.** 생중계 1채널 1시간 ≈ $0.4
- 회의 생중계 HLS 주소(`....m3u8`) 또는 생중계 페이지 주소

## 2. 설정

```bash
cp backend/.env.example backend/.env
```

최소한 이 넷을 채웁니다.

| 항목 | 값 |
|---|---|
| `OPENAI_API_KEY` | 발급받은 키 |
| `JWT_SECRET_KEY` | `openssl rand -hex 32` 로 만든 값 (비면 서버가 뜨지 않습니다) |
| `SUPABASE_URL` · `SUPABASE_KEY` · `SUPABASE_SCHEMA` | PostgREST 주소·키·스키마 |
| `ORG_NAME` | 기관 이름 (화면과 전사 프롬프트에 씁니다) |

그리고 **기관 전용 항목은 비웁니다** — `KMS_BASE_URL`, `COUNCIL_CALENDAR_URL`,
`COUNCILOR_API_BASE_URL`, `COUNCIL_ONAIR_API_URL`, `GGC_LOGIN_BASE_URL`.
비어 있으면 그 기능만 꺼집니다.

> ⚠ `SUPABASE_SCHEMA` 를 실제 스키마와 다르게 두면 **모든 쿼리가 406** 으로 죽습니다.
> 운영에서 실제로 겪은 장애입니다.

## 3. DB 만들기 — **자동으로 되지 않습니다**

서버는 기동할 때 마이그레이션을 돌리지 않습니다(`backend/start.sh` 는 uvicorn 만 띄웁니다).
`backend/migrations/` 의 SQL 을 **번호 순서대로** 직접 적용해야 합니다.

```bash
cd backend
python scripts/apply_migrations.py        # 또는 psql 로 001 부터 차례로
```

적용 뒤 **PostgREST 를 재시작**합니다. 스키마를 캐시하기 때문에 안 하면 새 표에 404 가 납니다.

```bash
# 쿠버네티스라면
kubectl -n <네임스페이스> rollout restart deploy/<postgrest-배포이름>
```

## 4. 띄우기

```bash
# 백엔드
cd backend && pip install -r requirements.txt && bash start.sh

# 프런트엔드
cd frontend && npm ci && npm run build && npm start
```

## 5. 채널 등록 — 여기가 핵심입니다

관리자로 로그인해 **시스템관리 → 채널 관리**(`/admin/channels`)로 갑니다.

1. **의회 고르기** — 전국 48곳(광역 17 + 경기 시·군 31)의 생중계 페이지 주소가 들어 있습니다.
   고르면 주소가 자동으로 채워집니다. 목록에 없으면 직접 넣습니다.
2. **[채널 자동 찾기]** — 페이지를 읽어 영상 주소(m3u8)를 찾습니다.
   찾은 것 중 `재생목록 확인됨` 인 항목이 기본 선택됩니다.
3. **[선택한 채널 등록]**

> **못 찾는 것이 정상일 수 있습니다.** 대부분의 의회 생중계는 **방송 중일 때만** 영상 주소가
> 드러납니다(서울·대구·충남·고양·성남에서 실측). 그때는 회의 시간에 다시 시도하거나,
> 브라우저 개발자도구(F12) → 네트워크 탭에서 `m3u8` 로 걸러 주소를 찾아 **직접 입력**하세요.
> 직접 입력은 언제나 동작합니다.

### 방송 중인지 어떻게 아나

채널마다 판정 방식을 고릅니다.

| 방식 | 언제 |
|---|---|
| **영상 주소로 자동 판정**(`probe`) | 기본값. 영상 주소를 주기적으로 받아 새 조각이 생기면 방송중으로 봅니다 |
| 기관 생중계 API(`ggc`) | 기관에 "지금 방송 중인 채널" 을 알려주는 API 가 있을 때 |
| 관리자가 직접(`manual`) | 자동 판정이 안 될 때. 회의 시작 전에 켜면 정해진 시간 뒤 자동으로 꺼집니다 |

## 6. 의원 명부 넣기 (선택이지만 권장)

명부가 없으면 자막은 나오지만 **화자 이름이 붙지 않습니다**. `councilors` 표에 이름·위원회를
넣으면 전사 프롬프트와 이름 교정이 그 명부를 씁니다. 기관마다 원천이 달라 수집 코드는
경기도의회용만 들어 있습니다(`backend/scripts/sync_councilors.py` 참고).

## 7. 비용 관리

- OpenAI 콘솔의 **월 하드 리밋**이 가장 확실한 상한입니다.
- `STT_MAX_CONCURRENT_CHANNELS` 가 동시에 전사할 채널 수를 막습니다.
- 다시보기 자동 자막(`VOD_AUTO_STT_*`)은 KMS 계열 시스템이 있을 때만 의미가 있습니다.

## 자주 막히는 곳

| 증상 | 원인 |
|---|---|
| 자막이 한 줄도 안 나온다 | 채널이 없거나, 방송 판정이 계속 "방송전" 입니다. `/admin/channels` 에서 **[지금 확인]** 을 눌러 영상 주소가 살아 있는지 보세요 |
| API 는 "정상" 인데 자막만 없다 | `LIVE_BATCH_MODEL` 이 계정에 권한 없는 모델일 수 있습니다. 관리자 화면의 OpenAI 상태는 모델 **목록**만 확인하므로 초록으로 보입니다 |
| 모든 화면이 500 | `SUPABASE_SCHEMA` 불일치(406) 또는 마이그레이션 미적용 |
| 파드가 안 뜬다 | `ADMIN_QUICK_PIN` Secret 미생성(쿠버네티스 매니페스트가 참조합니다) |
| 화자가 전부 "위원장" | 의원 명부가 비어 있습니다 |
