# 의회 서식 원본 (HWPX)

담당자가 실제로 쓰는 서식이다(2026-09-14 `.orca/drops/` 로 전달, 2026-09-16 반입).

| 파일 | 원래 이름 | 쓰임 |
|---|---|---|
| `monitoring.hwpx` | [서식1] 운영위 모니터링(업무보고) | 표 서식 프로필을 뽑아 모니터링 문서에 입힌다 |
| `datareq_list.hwpx` | [서식2] 운영위 자료요구 목록 | 자료요구 목록에 같은 방식 |
| `datareq_cover.hwpx` | [서식3] 운영위 의원 요구자료 | **파일 자체에 값을 채운다**(`ggc_doc /fill`) |

⚠ **`backend/data/` 가 아니라 `backend/app/data/` 다.** Dockerfile 이 `app/`·`migrations/` 만 복사해
`backend/data/` 는 운영 이미지에 없다(2026-09-15 에 의원 명단으로 실제로 겪었다).

⚠ 서식을 바꾸면 프로필 캐시 키(파일 해시)가 바뀌어 다음 문서 생성 때 자동으로 다시 뽑는다.
